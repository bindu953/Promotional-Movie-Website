
# The Crime Brothers – Promotional Movie Website

## Project Overview

The Crime Brothers is a fictional crime-thriller movie promotional website created using HTML and CSS.

The goal of this project was to design and develop a responsive, multi-page website that promotes a fictional movie and provides visitors with information about its storyline, cast, and crew.

This project also helped me practice Git, GitHub, and collaborative web development.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- Git and GitHub
- Visual Studio Code

## Features

- Responsive movie promotional website
- Navigation bar with Home, Synopsis, and Contact Us links
- Movie poster and promotional content
- Detailed movie synopsis
- Cast and crew information
- Contact information in the footer
- Hover effects on navigation links
- Responsive layouts for desktop, tablet, and mobile devices
- Dark-themed design with red accents to match the crime-thriller theme

## Website Pages

### Home Page (`index.html`)

The home page introduces The Crime Brothers movie and provides promotional information.

It includes navigation links to other sections of the website.

### Synopsis Page (`synopsis.html`)

The synopsis page provides detailed information about the movie's storyline.

It includes:
- Movie poster
- Movie synopsis
- Cast information
- Director and producer credits
- Contact information in the footer

## How to Run the Project

1. Clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension or a web browser.
4. Use the navigation menu to explore the website.

## What I Learned

Through this project, We learned how to:

- Structure a multi-page website using semantic HTML elements.
- Use CSS Flexbox to arrange and align webpage content.
- Apply CSS properties such as margin, padding, border-radius, and background colors.
- Create responsive layouts using media queries.
- Design navigation menus with hover effects.
- Link multiple HTML pages together.
- Organize images and CSS files in a project folder.
- Use Git branches, commits, and pull requests.
- Collaborate with team members using GitHub.

## Challenges Faced

One challenge was creating a responsive layout that displayed the movie poster, synopsis, and cast information correctly across different screen sizes.

Another challenge was positioning the footer below the main content and ensuring the navigation menu remained properly aligned.

These issues were resolved by improving the HTML structure, adjusting Flexbox properties, and adding media queries for smaller screens.

## Team Collaboration

This project was developed as part of a collaborative web development activity.

Team members contributed to different parts of the website, including page layout, styling, movie content, and navigation.

Git and GitHub were used to manage code changes, work with feature branches, and merge contributions through pull requests.
